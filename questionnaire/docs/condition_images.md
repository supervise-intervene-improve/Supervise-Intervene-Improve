# Condition reference images

The final comparison displays three equal-width condition references. The repository intentionally contains no invented scientific screenshots.

Place researcher-approved PNG files at these exact paths:

```text
assets/conditions/study1a/desktop_rgb.png
assets/conditions/study1a/vr_rgb.png
assets/conditions/study1a/vr_pointcloud.png
assets/conditions/study1b/kinesthetic_teaching.png
assets/conditions/study1b/motion_controller.png
assets/conditions/study1b/factr.png
```

Use screenshots with approximately the same aspect ratio and pixel dimensions. Crop consistently, show only the relevant interface/controller, and remove participant information, results, performance indicators, timestamps, notifications, and unrelated desktop content.

When a file is absent, Participant Mode displays a neutral condition-labelled placeholder. Experimenter Mode displays a warning naming every missing file. Restart or rerun Streamlit after replacing an image.
